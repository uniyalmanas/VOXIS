# VOXIS
### Voice & Gesture OS Control System

VOXIS is an AI-powered hands-free computer 
control system. Control your entire operating 
system using gestures and voice — no keyboard, 
no mouse, no touching required.

## Features
- Hand gesture cursor control
- Pinch to click
- Voice commands
- OS level control
- Works on any laptop with webcam

## Tech Stack
- Python 3.11
- MediaPipe
- OpenCV
- PyAutoGUI
- Google Speech API (coming soon)
- Gemini AI (coming soon)

## Setup
```bash
git clone https://github.com/uniyalmanas/VOXIS
cd VOXIS
python -m venv voxis_env
source voxis_env/Scripts/activate
pip install -r requirements.txt
python main.py
```
